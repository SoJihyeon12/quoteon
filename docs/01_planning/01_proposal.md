# 1. 영업사원을 위한 견적 생성 및 관리 시스템 (QuoteOn) 기획서

## 목차

- 1.0 영업사원을 위한 견적 생성 및 관리 시스템(QuoteOn) 기획서
- 1.1 기획 개요
- 1.2 주요 기능 요구사항
- 1.3 기술 스택 및 개발 환경

---

## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적

- 영업사원이 고객 상담 과정에서 제품을 탐색하고 견적서를 작성·관리할 수 있는 웹 기반 견적 생성 및 관리 시스템(QuoteOn) 구축.
- 기존 종이 견적서 또는 수기 작성 방식에서 발생하는 견적 작성 시간 증가, 정보 관리의 어려움 및 업무 비효율 개선.
- 제품 정보, 가격, 고객 정보 및 견적 내역을 시스템에서 통합 관리하여 영업 업무의 편의성과 정확성 향상.
- 상담 중 제품을 선택하고 수량 및 견적 금액을 실시간으로 확인할 수 있도록 하여 신속한 고객 응대 지원.
- 공급가액, 부가가치세 및 최종 합계 금액을 자동 계산하여 견적 작성 과정의 계산 오류 감소.
- 작성된 견적서를 미리보기 및 PDF 다운로드 기능으로 확인하고, 실제 이메일 발송을 통해 고객에게 전달할 수 있도록 제공.
- 이메일 발송 성공·실패 이력을 저장하여 발송 결과 확인 및 실패한 이메일 재발송 지원.
- 영업사원별 견적 작성 내역과 고객 정보를 관리하여 지속적인 영업 활동 및 과거 견적 내역 확인 지원.
- 관리자 페이지를 통해 회원 가입 승인, 사용자 관리, 제품 및 카테고리 관리, 전체 견적서 조회 등 서비스 운영에 필요한 기능 제공.
- React + Vite 기반 프론트엔드와 Spring Boot 기반 REST API 백엔드 간 비동기 데이터 통신 체계 구축.
- MySQL 데이터베이스를 활용하여 회원, 고객, 제품, 견적서, 견적 상세 내역 및 이메일 발송 이력을 체계적으로 저장하고 관리.

### 1.1.2 서비스 주요 특징

- 영업사원과 관리자 권한을 분리하여 역할에 따른 기능 및 데이터 접근 제어.
- 회원가입 후 관리자 승인을 거쳐 서비스를 이용할 수 있는 사용자 승인 체계 제공.
- 제품명, 제품 코드 및 키워드를 활용한 제품 검색과 카테고리별 탐색 기능 제공.
- 제품 상세 정보 및 대표 이미지, 추가 이미지 확인을 통한 상담 중 제품 정보 탐색 지원.
- 고객 선택 후 제품 및 수량을 구성하여 견적서를 작성할 수 있는 상담 작업대 제공.
- 제품 판매가를 부가세 별도 금액으로 관리하고, 공급가액·부가가치세·최종 합계 금액을 자동 계산.
- 견적 작성 당시의 제품명, 제품 코드 및 판매가를 저장하여 제품 정보 변경 후에도 기존 견적 금액 유지.
- 작성 중인 견적 취소 및 새로운 상담 시작 시 작성 내용 초기화 여부를 확인할 수 있는 견적 작업 관리 기능 제공.
- 견적서 PDF 생성 및 다운로드, 실제 이메일 발송을 통한 견적서 전달 기능 제공.
- 이메일 발송 성공·실패 이력을 저장하고 실패한 발송을 재시도할 수 있도록 지원.
- 발송 완료된 견적서는 수정할 수 없으며, 수정이 필요한 경우 새로운 견적서를 작성하도록 관리.
- 영업사원별 내 견적 목록과 고객 목록을 통해 과거 견적 및 고객 정보를 조회하고 관리.
- 제품 판매 중지와 삭제를 구분하여 판매 중지 제품은 신규 견적에서 선택할 수 없도록 하고, 견적에서 사용 중인 제품은 삭제 제한.
- 고객 정보는 실제 삭제 대신 비활성화하여 기존 견적과 연결된 정보를 유지.
- 관리자 전용 페이지에서 사용자 승인·관리, 제품·카테고리 관리 및 전체 견적서 조회 기능 제공.
- Spring JDBC의 JdbcTemplate 및 RowMapper를 활용한 데이터 접근과 객체 매핑.
- JUnit 기반 테스트를 통한 주요 서비스 로직 및 데이터 처리 검증.

## 1.2 주요 기능 요구사항

### 1.2.1 회원 및 인증 관리 기능

- 영업사원 회원가입(이메일, 비밀번호, 이름, 휴대폰 번호, 소속 회사 등).
- 가입 신청 후 관리자 승인 대기 상태 표시.
- 관리자 승인 완료 후 로그인 및 서비스 이용 가능.
- 이메일 및 비밀번호 기반 로그인 기능.
- 승인되지 않은 사용자 또는 이용이 제한된 사용자의 로그인 접근 제어.
- 로그인한 영업사원의 이름 및 계정 정보 표시.
- 로그아웃 기능 제공.
- 사용자 상태에 따른 로그인 제한 및 안내 화면 제공.
- 관리자와 영업사원의 권한을 구분하고 백엔드에서 권한 검증.
- 회원 비활성화 시 기존 고객 및 견적 데이터는 보존하고 로그인과 신규 견적 작성 제한.

### 1.2.2 제품 탐색 및 검색 기능

- 전체 제품 목록 조회.
- 카테고리별 제품 목록 탐색.
- 제품명, 제품 코드 및 키워드를 통한 검색.
- 제품 목록 페이징 처리.
- 제품 카드에 제품 이미지, 제품명, 제품 코드 및 가격 표시.
- 즐겨찾기 제품 등록 및 해제.
- 즐겨찾기 제품만 모아 조회하는 기능.
- 제품 상세 정보 조회(제품명, 제품 코드, 규격, 설명, 기준단가, 판매가, 대표 이미지 및 추가 이미지).
- 제품 상세 화면에서 대표 이미지와 추가 이미지 확인.
- 제품 상세 정보 확인 후 상담 작업대로 돌아갈 수 있는 화면 이동 기능.
- 판매 중지된 제품은 신규 견적에서 선택할 수 없도록 처리.
- 견적에서 사용 중인 제품은 삭제할 수 없도록 제한.
- 어떤 견적에서도 사용하지 않은 제품에 한해 실제 삭제 허용.

### 1.2.3 상담 작업대 및 견적 작성 기능

- 새로운 상담 작업 시작 및 견적 작성 화면 제공.
- 상담 작업대에서 고객 선택 및 고객 정보 확인.
- 고객 검색 및 고객 목록 조회 기능.
- 선택한 고객 정보와 상담 작성일 표시.
- 제품 목록에서 제품 선택 후 견적에 추가.
- 제품별 수량 설정 및 수량 변경.
- 견적에 추가된 제품의 목록, 판매가, 수량 및 금액 표시.
- 제품별 금액 및 견적 전체 금액 자동 계산.
- 공급가액, 부가가치세 및 총 견적 금액 계산.
- 견적 작성 중 제품 추가 및 수량 변경에 따른 금액 갱신.
- 견적서 미리보기 기능을 통한 작성 내용 확인.
- 작성 중인 견적 취소 기능 제공.
- 새로운 상담 시작 시 기존 작성 중인 견적을 초기화하기 전 사용자 확인.
- 작성 중인 견적의 저장 및 상태 관리.
- 제품 판매가는 부가세 별도 금액으로 적용하고 부가세는 공급가액의 10%로 계산.
- 견적 작성 당시의 제품명, 제품 코드 및 판매가를 저장하여 기존 견적의 금액 유지.

### 1.2.4 견적서 생성 및 전달 기능

- 고객 정보와 선택한 제품 내역을 기반으로 견적서 생성.
- 견적서 번호 자동 생성 및 중복 방지.
- 견적서에 담당자, 고객 정보, 견적 작성일 및 견적 금액 표시.
- 견적서에 제품명, 제품 코드, 제조사, 판매가, 수량 및 금액 표시.
- 공급가액, 부가가치세 및 총 견적 금액 표시.
- 견적서 미리보기 기능 제공.
- 견적서 PDF 다운로드 기능.
- 네이버 메일 SMTP를 이용한 실제 이메일 발송.
- 수신 이메일 주소, 이메일 제목 및 발송 내용 확인.
- 생성된 PDF 견적서를 이메일에 첨부하여 발송.
- 이메일 발송 성공·실패 결과 표시.
- 이메일 발송 이력 저장 및 발송 결과 확인.
- 발송 실패 사유 확인 및 실패한 이메일 재발송.
- 이메일 발송 성공 시 견적서 상태를 발송 완료로 변경.
- 이메일 발송 실패 시 견적서를 발송 완료 상태로 변경하지 않도록 처리.
- 발송 완료된 견적서는 수정할 수 없도록 제한하고, 수정이 필요한 경우 새로운 견적서 작성.
- 견적서 삭제 시 관련 견적 상세 항목 및 이메일 발송 이력 함께 삭제.

### 1.2.5 내 견적 관리 기능

- 로그인한 영업사원이 작성한 견적 목록 조회.
- 견적 작성일, 고객명, 견적 금액 및 견적 상태 표시.
- 작성일 및 고객명 등을 기준으로 견적 검색.
- 견적 목록 페이징 처리.
- 견적 상세 정보 조회.
- 견적서 미리보기 및 PDF 다운로드 기능.
- 견적서 이메일 발송 기능.
- 작성 중, 발송 완료 등 견적 상태 확인.
- 이메일 발송 이력 및 발송 결과 확인.
- 발송 실패한 이메일 재발송.
- 발송 완료된 견적서 수정 제한.
- 견적서 삭제 시 연결된 견적 상세 항목과 이메일 발송 이력 함께 삭제.
- 본인이 작성한 견적 내역을 중심으로 조회 및 관리.

### 1.2.6 고객 관리 기능

- 영업사원별 고객 목록 조회.
- 개인 고객 및 기업 고객 구분 관리.
- 고객명 및 연락처를 기준으로 고객 검색.
- 고객 등록 기능(고객명, 고객 유형, 연락처, 이메일, 주소 및 메모).
- 고객 상세 정보 조회.
- 고객 상세 정보 수정.
- 고객 목록 페이징 처리.
- 고객 선택 후 해당 고객을 대상으로 견적 작성.
- 고객 활성·비활성 상태 관리.
- 고객 비활성화 시 신규 견적 작성에서 선택할 수 없도록 처리.
- 고객 비활성화 후에도 기존 견적과 연결된 고객 정보 유지.

### 1.2.7 관리자 관리 기능

#### 관리자 인증 및 권한 관리

- 관리자 계정 기반 로그인 및 관리자 페이지 접근 권한 관리.
- 일반 영업사원과 관리자 간 접근 권한 분리.
- 관리자 전용 대시보드 및 관리 메뉴 제공.
- 백엔드에서 관리자 권한 및 요청 데이터에 대한 접근 권한 검증.

#### 통계 대시보드

- 오늘 작성된 견적 수 조회.
- 이번 달 견적 금액 조회.
- 승인 대기 중인 회원 수 조회.
- 활성 사용자 수 조회.
- 인기 제품 현황 확인.
- 이번 달 사용자별 견적 작성 수 통계 확인.

#### 회원 가입 승인 및 사용자 관리

- 가입 승인 대기 회원 목록 조회.
- 회원명, 이메일, 휴대폰 번호 및 소속 회사 정보 확인.
- 회원 가입 신청일 및 승인 상태 확인.
- 가입 승인 및 승인 거절 처리.
- 전체 사용자 목록 조회 및 검색.
- 사용자 상세 정보 수정.
- 사용자 계정 활성화 및 비활성화 처리.
- 이용 제한 상태인 사용자의 로그인 및 서비스 접근 제어.
- 회원 비활성화 시 기존 고객 및 견적 데이터 보존.

#### 카테고리 관리

- 전체 제품 카테고리 목록 조회.
- 카테고리 추가 및 수정.
- 상위 카테고리와 하위 카테고리 관리.
- 카테고리 삭제 시 하위 카테고리 및 관련 제품 정보의 처리 여부 확인.
- 카테고리 변경 사항을 제품 탐색 화면에 반영.

#### 제품 관리

- 전체 제품 목록 조회 및 검색.
- 제품 등록 기능(제품명, 제품 코드, 카테고리, 기준단가, 판매가, 규격, 제조사 및 설명).
- 제품 대표 이미지 및 추가 이미지 등록.
- 제품 상세 정보 조회.
- 제품 정보 수정.
- 제품 판매 중지 처리.
- 제품 삭제 기능 및 삭제 전 사용자 확인.
- 판매 중지 제품은 신규 견적에서 선택할 수 없도록 처리.
- 견적에서 사용 중인 제품은 삭제할 수 없도록 제한.
- 어떤 견적에서도 사용하지 않은 제품은 실제 삭제 가능.
- 제품 판매 중지 또는 삭제 시 조건에 따른 안내 메시지 표시.
- 제품 정보 변경 사항을 영업사원 제품 탐색 화면에 반영.

#### 견적서 관리

- 전체 영업사원이 작성한 견적서 목록 조회.
- 작성자, 고객명, 제품 키워드 및 견적 상태를 기준으로 검색.
- 견적 작성일, 작성자, 고객명, 견적 금액 및 상태 확인.
- 견적서 상세 정보 조회.
- 견적서에 포함된 고객 정보 및 제품 내역 확인.

## 1.3 기술 스택 및 개발 환경

### 1.3.1 프론트엔드

- React: 컴포넌트 기반 UI 개발 및 화면 상태 관리.
- Vite: 프론트엔드 개발 서버 및 빌드 환경 구성.
- HTML5, CSS3, JavaScript: 웹 화면 구성 및 사용자 인터랙션 구현.
- REST API 비동기 통신을 통한 백엔드 데이터 연동.

### 1.3.2 백엔드

- Java: 백엔드 비즈니스 로직 구현.
- Spring Boot: REST API 및 애플리케이션 서버 구축.
- Spring MVC: 요청 처리, Controller 구성 및 서비스 로직 연계.
- Spring JDBC: JdbcTemplate 기반 데이터 접근 및 SQL 실행.
- RowMapper: 조회 결과를 Java 객체로 매핑.
- JUnit: 서비스 및 데이터 처리 로직 테스트.
- 네이버 메일 SMTP: 고객에게 견적서 PDF를 실제 이메일로 발송.
- PDF 생성 라이브러리: 견적서 PDF 생성 및 다운로드 기능 구현.

### 1.3.3 데이터베이스 및 개발 환경

- MySQL: 회원, 고객, 제품, 카테고리, 즐겨찾기, 견적서, 견적 상세 항목 및 이메일 발송 이력 저장.
- IntelliJ IDEA: Spring Boot 백엔드 개발.
- Cursor: React 프론트엔드 개발.
- Git 및 GitHub: 소스 코드 버전 관리 및 프로젝트 파일 관리.
- `schema.sql`과 `data.sql`을 분리하여 테이블 생성과 초기 테스트 데이터 관리.
- 데이터베이스의 외래 키와 제약조건을 활용하여 데이터 관계 및 무결성 관리.
- 견적서 번호의 중복 방지를 위한 UNIQUE 제약조건 적용.
- 금액 데이터는 DECIMAL 자료형으로 관리하고 부가세 계산 및 반올림 규칙 통일.
- 날짜와 시간은 한국 시간 기준으로 일관되게 관리.
- 제품 이미지 파일은 프로젝트 내 로컬 이미지 폴더에 저장하고 데이터베이스에는 이미지 경로 저장.
- 비밀번호는 단방향 해시 방식으로 저장하고 SMTP 계정 비밀번호는 환경변수로 관리.
- 테스트 데이터에는 실제 개인정보와 민감한 인증 정보를 포함하지 않도록 관리.
