## 1. 서비스 화면 구성 개요

### 1.1 주요 화면 목록

#### 사용자 화면

- 로그인 화면 (GET `/login`)
- 회원가입 화면 (GET `/signup`)
- 회원가입 승인 대기 화면 (GET `/signup/pending`)
- 이용 제한 화면 (GET `/access-restricted`)
- 로그아웃 버튼이 있는 메인 화면 (GET `/consultation`)
- 로그아웃 확인 팝업 (GET `/consultation?dialog=logout`)
- 상담 작업대 - 새 상담 시 (GET `/consultation?mode=new`)
- 상담 작업대 - 고객 선택 팝업 (GET `/consultation/customers`)
- 상담 작업대 - 견적 진행 중 (GET `/consultation`)
- 제품 상세 팝업 (GET `/products/{productId}`)
- 제품 상세 - 이미지 확인 팝업 (GET `/products/{productId}/images`)
- 즐겨찾기 화면 (GET `/consultation?filter=favorites`)
- 상담 작업대 - 견적 취소 확인 팝업 (GET `/consultation?dialog=cancel-quote`)
- 상담 작업대 - 새 상담 시작 확인 팝업 (GET `/consultation?dialog=new-consultation`)
- 견적서 미리보기 화면 (GET `/quotes/preview`)
- 정식 견적서 화면 (GET `/quotes/{quoteId}`)
- 견적서 이메일 전송 화면 (GET `/quotes/{quoteId}/email`)
- 내 견적 목록 화면 (GET `/quotes/my`)
- 견적서 확인 화면 (GET `/quotes/{quoteId}/view`)
- 고객 목록 화면 (GET `/customers`)
- 고객 등록 화면 (GET `/customers/new`)
- 고객 상세 정보 확인 화면 (GET `/customers/{customerId}`)
- 고객 상세 정보 수정 화면 (GET `/customers/{customerId}/edit`)

#### 관리자 화면

- 관리자 통계 대시보드 (GET `/admin/dashboard`)
- 관리자 사용자 가입 승인 화면 (GET `/admin/members/pending`)
- 관리자 사용자 목록 화면 (GET `/admin/members`)
- 관리자 사용자 정보 수정 화면 (GET `/admin/members/{memberId}/edit`)
- 관리자 카테고리 관리 화면 (GET `/admin/categories`)
- 관리자 제품 관리 목록 화면 (GET `/admin/products`)
- 관리자 제품 등록 화면 (GET `/admin/products/new`)
- 관리자 제품 상세 정보 확인 화면 (GET `/admin/products/{productId}`)
- 관리자 제품 정보 수정 화면 (GET `/admin/products/{productId}/edit`)
- 관리자 제품 판매 중지 확인 팝업 - 견적 포함 제품 (GET `/admin/products/{productId}/stop-confirm?usage=used`)
- 관리자 제품 판매 중지 확인 팝업 - 견적 미포함 제품 (GET `/admin/products/{productId}/stop-confirm?usage=unused`)
- 관리자 제품 삭제 확인 팝업 - 견적 포함 제품 (GET `/admin/products/{productId}/delete-confirm?usage=used`)
- 관리자 제품 삭제 확인 팝업 - 견적 미포함 제품 (GET `/admin/products/{productId}/delete-confirm?usage=unused`)
- 관리자 견적서 목록 화면 (GET `/admin/quotes`)
- 관리자 견적서 상세 보기 화면 (GET `/admin/quotes/{quoteId}`)

## 2. 주요 화면별 명세

### 2.1 로그인 화면 (GET `/login`)
<img src="img.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 상단 영역: QuoteOn 서비스 로고
  - 입력 영역: 이메일, 비밀번호
  - 하단 영역: 로그인 버튼, 회원가입 링크

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
  - 이메일: 필수 입력 항목
  - 비밀번호: 필수 입력 항목
  - 이메일 형식 및 입력값 확인

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 로그인 버튼 클릭 시 입력값을 검증한 후 로그인 처리
  - 로그인 성공 시 회원 상태에 따라 서비스 화면으로 이동
  - 로그인 실패 시 오류 메시지 출력
  - 회원가입 링크 클릭 시 회원가입 화면으로 이동

### 2.2 회원가입 화면 (GET `/signup`)
<img src="img_1.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 상단 영역: 회원가입 제목
  - 가입 구분 선택 영역: 영업사원, 관리자
  - 입력 영역:
    - 이름
    - 이메일
    - 비밀번호
    - 비밀번호 확인
    - 휴대폰
    - 소속 회사
  - 하단 영역:
    - 가입 신청 버튼
    - 관리자 승인 후 이용할 수 있다는 안내 문구
    - 로그인으로 돌아가기 링크

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
  - 가입 구분: 영업사원 또는 관리자 선택
  - 이름: 필수 입력 항목
  - 이메일: 필수 입력 항목, 이메일 형식 및 중복 여부 확인
  - 비밀번호: 필수 입력 항목
  - 비밀번호 확인: 비밀번호 일치 여부 확인
  - 휴대폰: 연락처 입력
  - 소속 회사: 회사명 입력

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 가입 신청 버튼 클릭 시 입력값 검증 후 회원가입 신청
  - 가입 신청 완료 후 회원가입 승인 대기 화면으로 이동
  - 회원가입 신청 후 관리자 승인 완료 전까지 서비스 이용 제한
  - 로그인으로 돌아가기 클릭 시 로그인 화면으로 이동

### 2.3 회원가입 승인 대기 화면 (GET `/signup/pending`)
<img src="img_2.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 상단 영역: QuoteOn 서비스 로고
  - 안내 영역:
    - 승인 대기 제목
    - 가입 신청 접수 및 관리자 승인 후 로그인할 수 있다는 안내 문구
  - 회원 정보:
    - 이름
    - 소속
    - 이메일
  - 하단 영역: 로그아웃 버튼

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 관리자 승인 대기 상태임을 안내
  - 가입 신청이 접수되었으며 관리자 승인 후 로그인할 수 있음을 안내
  - 신청한 회원의 이름, 소속, 이메일 정보 표시
  - 로그아웃 버튼 클릭 시 로그아웃 처리

### 2.4 이용 제한 화면 (GET `/access-restricted`)
<img src="img_3.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 상단 영역: QuoteOn 서비스 로고
  - 안내 영역:
    - 이용 제한 제목
    - 계정이 비활성화되어 로그인할 수 없다는 안내 문구
    - 관리자에게 문의하라는 안내 문구
  - 제한 정보:
    - 사유
    - 비활성 처리 상태
  - 하단 영역: 로그인으로 이동 버튼

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 비활성화된 계정의 로그인 및 서비스 이용 제한 안내
  - 계정의 비활성화 사유 표시
  - 로그인으로 이동 버튼 클릭 시 로그인 화면으로 이동

### 2.5 로그아웃 버튼이 있는 메인 화면 (GET `/consultation`)
<img src="img_4.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 상단 영역:
    - QuoteOn 로고
    - 상담, 내 견적, 고객 메뉴
    - 로그인 사용자 정보
    - 로그아웃 버튼
  - 제품 영역:
    - 제품명, 제품 코드, 키워드 검색창
    - 즐겨찾기 필터
    - 새 상담 버튼
    - 카테고리 목록
    - 제품 카드
  - 견적 영역:
    - 고객 정보
    - 작성 견적 정보
    - 작성일
    - 제품 및 금액 정보
    - 공급가액, 부가세, 총금액
    - 견적서 저장 및 미리보기 버튼

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 로그아웃 버튼 클릭 시 로그아웃 확인 팝업 표시
  - 로그아웃 확인 후 로그아웃 처리 및 로그인 화면으로 이동
  - 상담, 내 견적, 고객 메뉴 클릭 시 해당 화면으로 이동
  - 로그인한 사용자 계정에 따라 사용자 정보 표시
  - 사용자 계정 영역 오른쪽에 로그아웃 버튼 표시

### 2.6 로그아웃 시 안내 팝업 (GET `/consultation?dialog=logout`)
<img src="img_5.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 팝업 제목: 로그아웃하시겠습니까?
  - 안내 문구: 로그아웃하면 로그인 화면으로 이동한다는 안내
  - 버튼: 취소, 로그아웃
  - 팝업 닫기 버튼(X)

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 취소 버튼 클릭 시 팝업을 닫고 현재 화면 유지
  - 로그아웃 버튼 클릭 시 로그아웃 처리 후 로그인 화면으로 이동
  - X 버튼 클릭 시 팝업 닫기

### 2.7 상담 작업대 - 새 상담 시 (GET `/consultation?mode=new`)
<img src="img_6.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 상단 메뉴:
    - QuoteOn 로고
    - 상담, 내 견적, 고객 메뉴
    - 로그인 사용자 정보
  - 제품 검색 영역:
    - 제품명, 제품 코드, 키워드 검색창
    - 즐겨찾기 필터
    - 새 상담 버튼
  - 카테고리 영역:
    - 전체 카테고리
    - 상위 카테고리 및 하위 카테고리
  - 제품 목록:
    - 제품 이미지
    - 제품명
    - 제품 코드
    - 가격
    - 즐겨찾기 표시
  - 견적 영역:
    - 고객 선택 영역
    - 작성일
    - 제품 목록
    - 수량 및 가격 정보
    - 공급가액, 부가세, 총금액
    - 견적서 저장 및 미리보기 버튼

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 새 상담 시작 시 견적 작성 영역을 초기화
  - 고객 선택 영역 클릭 시 고객 선택 팝업 표시
  - 제품 카드 클릭 시 제품 상세 팝업 표시
  - 즐겨찾기 아이콘 클릭 시 제품 즐겨찾기 상태 변경
  - 제품 선택 후 견적 항목에 추가
  - 견적서 미리보기 버튼 클릭 시 견적서 미리보기 화면으로 이동

### 2.8 상담 작업대 - 고객 선택 팝업 (GET `/consultation/customers`)
<img src="img_7.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 고객 검색 영역:
    - 고객명 또는 연락처 검색창
  - 고객 목록:
    - 고객명
    - 연락처
    - 고객 구분
  - 고객 선택 버튼
  - 페이지네이션
  - 팝업 닫기 버튼(X)

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
  - 고객 검색어 입력
  - 고객명 또는 연락처를 기준으로 검색

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 검색어에 따라 고객 목록 조회
  - 고객 목록에서 고객 선택 시 상담 작업대에 고객 정보 반영
  - 선택한 고객 정보는 견적 작성 영역에 표시
  - 고객 선택 완료 후 상담 작업대로 복귀
  - X 버튼 클릭 시 팝업 닫기

### 2.9 상담 작업대 - 견적 진행 중 (GET `/consultation`)
<img src="img_8.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 제품 목록 및 카테고리
  - 선택한 고객 정보
  - 견적 작성일
  - 선택 제품 정보:
    - 제품명
    - 제품 코드
    - 수량
    - 단가 및 금액
  - 금액 정보:
    - 공급가액
    - 부가세
    - 총금액
  - 결제 방식
  - 견적 메모
  - 견적 취소 버튼
  - 견적서 저장 및 미리보기 버튼

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
  - 견적에 추가할 제품 선택
  - 제품별 수량 입력 및 변경
  - 수량은 금액 계산이 가능한 유효한 값으로 입력
  - 결제 방식 선택
  - 견적 메모 입력

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 제품을 추가하면 견적 항목에 반영
  - 제품을 추가하거나 수량을 변경하면 공급가액, 부가세, 총금액 재계산
  - 부가세는 공급가액의 10%로 계산
  - 고객 정보가 없는 경우 고객을 선택하도록 안내
  - 결제 방식 선택 정보는 견적 정보에 반영
  - 견적 메모는 내부 관리용 정보로 사용
  - 견적 취소 버튼 클릭 시 견적 취소 확인 팝업 표시
  - 견적서 미리보기 버튼 클릭 시 견적서 미리보기 화면으로 이동

### 2.10 제품 상세 팝업 (GET `/products/{productId}`)
<img src="img_9.png" width="500">

- 출력 데이터 항목 (Output Data):
  - 제품명 및 즐겨찾기 표시
  - 대표 이미지 영역
  - 대표 이미지 및 상세 이미지 선택 버튼
  - 제품 코드
  - 제품명
  - 규격
  - 설명
  - 제품 가격
  - 수량 선택 영역
  - 견적에 추가 버튼
  - 팝업 닫기 버튼(X)

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
  - 제품 수량 선택
  - 견적에 추가할 수량 확인

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 제품 이미지와 상세 정보 표시
  - 대표 이미지 및 상세 이미지 선택 버튼 클릭 시 해당 이미지 표시
  - 수량 변경 시 선택 수량 반영
  - 견적에 추가 버튼 클릭 시 선택 제품과 수량을 견적에 반영
  - 제품명 옆 즐겨찾기 아이콘 클릭 시 즐겨찾기 상태 변경
  - X 버튼 클릭 시 팝업 닫기

### 2.11 제품 상세 - 이미지 확인 팝업 (GET `/products/{productId}/images`)

    - 상세 보기 버튼
  - 페이지네이션

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
  - 작성일 기준 검색
  - 작성자 기준 검색
  - 고객명 기준 검색
  - 제품 키워드 기준 검색

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 관리자 권한으로 전체 견적서 목록 조회
  - 검색 조건에 따라 견적서 목록 필터링
  - 견적 상태 표시
  - 상세 보기 버튼 클릭 시 해당 견적서 상세 화면으로 이동
  - 발송 완료 또는 비공개 상태의 견적서 확인 가능
  - 페이지네이션을 통해 목록 이동

  - 견적서 상세 내용:

    - 견적번호
    - 담당자 및 고객 정보
    - 공급자 정보

    - 제품 규격
    - 수량
    - 단가
    - 금액

    - 작성자

  - 기능 버튼:
    - PDF 다운로드

    - 삭제 버튼

  - 견적 비공개 처리 여부 확인
  - 견적 삭제 여부 확인

- 화면 제어 및 권한 규칙 (Behavior Rules):
  - 관리자는 선택한 견적서의 상세 내용 확인 가능
  - PDF 다운로드 버튼 클릭 시 PDF 파일 다운로드
  - 이미지 다운로드 버튼 클릭 시 이미지 파일 다운로드
  - 비공개 버튼 클릭 시 견적서를 비공개 상태로 변경
  - 비공개 상태의 견적서는 관리자만 확인 가능
  - 공개 전환 기능을 통해 비공개 견적서의 상태 복구 가능
  - 삭제 버튼 클릭 시 견적서 삭제 처리
  - 견적서 삭제 시 관련 견적 항목과 이메일 발송 이력도 함께 삭제
  - 견적 상세 내용은 별도 미리보기 버튼 없이 상세 화면에서 확인
